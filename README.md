# SwiftDrop — Full-stack delivery web app

SwiftDrop is a responsive food-delivery MVP designed for Ilorin, Nigeria. It includes a customer storefront, persistent PostgreSQL-backed products and orders, order tracking, and an admin dashboard.

## What is included

- Customer menu with categories, search and shopping cart
- Server-side price calculation and order creation
- Order tracking by tracking code
- Admin dashboard at `/admin.html` to view orders, change status and add menu items
- PostgreSQL schema and starter menu seeded on first run
- Optional Paystack checkout link initialization (payment verification is not included yet)
- Installable PWA manifest and service worker for supported mobile/desktop browsers
- Render Blueprint file (`render.yaml`) to help create the web service and database

## Deployment (Render)

1. Create or sign in to GitHub and create a **private** repository for this project.
2. Upload the contents of this folder to the repository root (the `package.json`, `server.js`, `render.yaml`, and `public/` folder must be at the root).
3. In Render, choose **New → Blueprint**, connect that GitHub repository, and review the services before applying.
4. Render will read `render.yaml` to create a web service and PostgreSQL database. Review the database plan and price/retention terms shown in your account before confirming.
5. Once deployed, open the generated `onrender.com` URL and test `/api/health`. It should return `{"ok":true,"service":"SwiftDrop API"}`.
6. Open `/admin.html`. The admin key is generated by Render as `ADMIN_KEY`; reveal it in the service's environment settings when you need to sign in. Never share it with customers or put it in public code.

If Render rejects the database plan in the Blueprint, create a PostgreSQL database manually using a plan currently available to your account, then set the web service's `DATABASE_URL` to its internal connection string. Only set `PGSSL=true` if the selected database provider requires SSL for that connection.

## Run locally

Requires Node.js 20+ and PostgreSQL.

1. Copy `.env.example` to `.env`.
2. Set `DATABASE_URL` and a unique `ADMIN_KEY` with at least 20 characters.
3. Run `npm install`, then `npm start`.
4. Visit `http://localhost:3000`.

## Before sharing with customers

This is an MVP, not a fully production-audited marketplace. Test the deployed app end-to-end before advertising it. The current version does not include customer accounts, rider accounts/assignment, automatic delivery-fee calculation, or verified online payment webhooks. Pay-on-delivery is the safe default. Do not accept online payments until Paystack transaction verification and webhook handling have been added and tested. Add clear business contact details, delivery coverage/fees, privacy policy, and terms before public launch.
